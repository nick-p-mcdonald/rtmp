Windows Setup

1. Install Nginx with RTMP Module on Windows

  1. Download Nginx with RTMP Module:
    • Go to the Nginx RTMP Module GitHub page and download the zip file.
    • Extract the contents to a folder, e.g., C:\nginx.
  2. Install Nginx:
    • Open a command prompt and navigate to the Nginx folder: 
      cd C:\nginx
    • Run Nginx: 
      start nginx
    • Note: You may not see any output in the command prompt when you run Nginx.

2. Configure Nginx for RTMP

  1. Edit the Nginx Configuration File:
    • Open nginx.conf located in the conf directory of your Nginx folder.
    • Add the following RTMP configuration: 
      worker_processes  1;

events {
    worker_connections  1024;
}

rtmp {
    server {
        listen 1935;
        chunk_size 4096;

        application live {
            live on;
            record off;
        }
    }
}
  2. Restart Nginx:
    • In the command prompt, stop Nginx: 
      nginx -s stop
    • Start Nginx again: 
      start nginx
  3. Verify Nginx is Running:
    • Open a web browser and navigate to http://localhost. If Nginx is running, you should see the default Nginx welcome page.

3. Install FFmpeg on Windows

  1. Download FFmpeg:
    • Go to the FFmpeg download page and download the latest release.
    • Extract the contents to a folder, e.g., C:\ffmpeg.

4. Run the FFmpeg Command

  1. Open a New Command Prompt:
    • Navigate to the FFmpeg folder: 
      cd C:\ffmpeg\bin
  2. Run the FFmpeg Command:
    • Replace cam_private_ip with the actual IP address of your camera: 
      ffmpeg -i rtsp://cam_private_ip:554/video -vf scale=854:480 -vcodec libx264 -acodec aac -f flv rtmp://localhost/live/mystream
    • Note: The mystream part of the URL is arbitrary and can be any word you choose.
  3. Run Nginx and FFmpeg in Separate Command Windows:
    • Ensure Nginx is running in one command prompt window and leave it open and undisturbed. Nginx is a web server, so it must stay open to allow the stream to work.
    • Open another command prompt window to run the FFmpeg command. FFmpeg is a video encoder program that processes and converts video streams.

Linux Setup

1. Install VirtualBox and Ubuntu (Optional)

  1. Download VirtualBox: Install it from VirtualBox.
  2. Download the Ubuntu ISO: Get the latest version from Ubuntu’s download page.
  3. Create a Virtual Machine:
    • Open VirtualBox and click on "New".
    • Name your VM, select the type (Linux), and version (Ubuntu x64).
    • Allocate a minimum of 2GB RAM.
    • Create a Virtual Hard Disk using VDI format and allocate at least 20GB.
    • Select the Ubuntu ISO you downloaded as the optical disk for the VM.
  4. Install Ubuntu: Start the VM and proceed through the installation prompts to set up Ubuntu.
  5. Log In and update the system: 
    sudo apt update && sudo apt upgrade
  6. Configure Network Settings for Bridging:
    • In VirtualBox, go to the settings of your VM.
    • Navigate to the "Network" section.
    • Change "Attached to" to "Bridged Adapter".
    • Select your network adapter from the dropdown menu.
    • Click "OK" to save the settings.

2. Install and Configure Nginx with RTMP Module

  1. Install Nginx and dependencies: 
    sudo apt install nginx ffmpeg
    sudo apt install libnginx-mod-rtmp
  2. Configure Nginx:
    • Edit the Nginx configuration: 
      sudo nano /etc/nginx/nginx.conf
    • Add RTMP block: 
      rtmp {
          server {
              listen 1935;
              chunk_size 4096;

              application live {
                  live on;
                  record off;
              }
          }
      }
    • Save and close the file.
    • Restart Nginx: 
      sudo systemctl restart nginx
    • Verify Nginx installation with RTMP: 
      nginx -V 2>&1 | grep rtmp

3. Set Up FFmpeg

  1. Stream from RTSP to RTMP: 
    ffmpeg -i rtsp://local_camera_ip:554/video -vcodec libx264 -acodec aac -f flv rtmp://localhost/live/mystream
  2. Verify stream with FFprobe: 
    ffprobe rtmp://localhost/live/mystream

Router Setup for Remote Access

  1. Configure Port Forwarding:
    • Log in to your router using http://tplinkwifi.net or your router’s IP.
    • Navigate to NAT Forwarding > Virtual Servers:
    • Click Add and set:
      • Service Port: 1935
      • Internal IP: Your VM’s local IP or Windows machine IP (e.g., 192.168.0.100)
      • Internal Port: 1935
      • Protocol: TCP
      • Status: Enabled
    • Save your settings.
  2. Enable Remote Management (if needed):
    • Navigate to System Tools > Administration:
    • Enable Remote Management and set the Remote Management IP Address to 0.0.0.0.
    • Save your settings.
  3. Obtain your public IP:
    • Use a site like WhatIsMyIP to find your server's public IP address.

Access RTMP Stream Remotely Using VLC

  1. Open VLC.
  2. Navigate to Media > Open Network Stream.
  3. Enter the RTMP URL: 
    rtmp://your_public_ip_or_domain/live/mystream
  4. Click Play to start streaming.
